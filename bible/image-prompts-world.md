world-fashion.md). Every woman here is 18 or older and is drawn with a
mature face and adult proportions. Canon characters start with their name
and "from Honkai Impact 3rd" so the generator picks up the design. Each
prompt ends with the style line, so it can be copied as it is. Use the
negative prompt below with every one (not the one in image-prompts.md,
which blocks revealing clothing).

# Formatting

## System notices and speech

The System's notices and its speech go in square brackets, each line on its
own line. A notice that sounds in Eros's head starts with [Ding!] on its own
line. When a dialogue tag is needed, the bracketed speech can share a line
with it, like normal speech: [Good morning,] the System said.

```
[Ding!]
[Imaginary Simulation System bound.]
[There you are, Eros.]
```

The System's conversational voice is cunning and playful. It usually uses
no form of address; use "Eros" sparingly and do not append "Host" to its
replies. Notices and panels remain clear and exact. An occasional ♪ can
mark a teasing or indulgent line; use it rarely, never as a routine ending.
See [characters/the-system.md](characters/the-system.md) for the voice.

## Eros talking to the System

He can talk out loud or in his head. Out loud uses normal quotation marks.
In his head uses italics with no quotation marks.

## Panels

A panel opens with its name in brackets, then plain lines.

```
[Status]
Name: Eros
Age: 18
Combat Rating: Civilian
Honkai Adaptability: F
Soul: Whole
Gifts: None
Fate Fragments: 0
```

## Choices

```
[Begin first simulation? Yes / No]
```

## Life-node choices

Before immersion, show the node's date or stage, its fixed conditions and
the available choices. The System may comment separately, but the menu
must distinguish a locked fact from a decision.

```
[Life node: before the transfer]
Name: Eros (Fixed)
Age at immersion: 18 (Fixed)
School and start: Chiba Academy, October 1, 2013 (Fixed)
Preparation: Social practice / School procedures / Conditioning
[Choose one.]
```

## Run logs

Normal runs are mostly told as log lines in the second person, one event per
line, with the date or age first.

```
[1999, March. You arrive at the outpost. It is colder than the file said.]
[1999, April. You fix the generator. Nobody thanks you.]
```

## Gifts and items

Name first, color in parentheses: [Light Sleeper (White)].

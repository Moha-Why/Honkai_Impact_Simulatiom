# Simulation System

The Imaginary Simulation System tells Eros the simulations aren't real. They are:
each run writes a branch into the Imaginary Tree.

## Simulation types

- **Normal simulations:** classic life simulations. The run plays out, mostly
  as log lines, until Eros dies; then he settles rewards based on what the run
  achieved. Death ends the run.
- **Heroine simulations:** built around one heroine, with meters and
  objectives. Death resets the run at a soul cost. Failing the objectives
  lets him end the run or restart it.

## Starts

- Every heroine run gives Eros an identity and a starting point that is
  normal or bad, usually with a hidden route toward the heroine.
- **Immediate start:** he arrives in his identity with his memories intact.
- **Childhood start:** his memories and the System stay sealed until the
  heroine turns 18. He lives the childhood as a real child her age, the
  years are summarized in log lines, and nothing romantic happens.
- Meters and objectives only activate once the heroine is 18 or older.

## Meters

- Heroine: **Affection**, **Trust**, **Corruption**
- World: **Fate Deviation**, which measures how much he has changed
  history. The higher it climbs, the harder the world pushes back.

## Objectives

- Several run at once. Completing one is enough; each extra one raises the
  reward's size and rarity.
- Once at least one objective is complete, his next death ends the run as a
  success instead of resetting it.

## Aftermath

- After a heroine run, Eros's identity in it is treated as dead or missing.
  A later run with the same heroine continues from there.
- Failed runs reset completely. He can retry later from a different start.
- **Pre-era heroines:** a completed run brings her back to the present with
  memories of the final loop only. The edit is local to her own thread. She
  arrives after a delay, often somewhere dangerous, and weak at first.
- **Living heroines:** a completed run collapses into her as echoes (dreams,
  déjà vu, a sense she knows him), stronger with each objective completed.
  The echoes only surface once the real timeline reaches the run's start.

## Entering a run

- He enters through sleep. His body stays put, and one run takes about one
  night however many years pass inside.
- One normal run per day is free.
- Heroine runs unlock when the System decides and announces it.
